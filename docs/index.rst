dfoptimizer
===========

DFOptimizer is a streaming runtime I/O optimizer for HPC/AI workloads: it
turns DFDiagnoser's diagnosis findings into concrete knob-change ActionPlans
and, online, feeds them back to the running application to re-tune it in
flight.
